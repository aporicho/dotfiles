# TUI 仪表盘

裸 `dot` 命令进入，合成器风格多面板仪表盘。

---

## 布局

```
┌────────┬────────┬────────┬────────┬────────┬────────┬────────┬────────┐
│        │        │        │        │        │        │        │        │
│  BIN   │  GIT   │ KITTY  │NEOVIDE │  NVIM  │  YAZI  │  ZSH   │ + ADD  │
│   ●    │   ●    │   ●    │   ●    │   ●    │   ●    │  ●     │   a    │
│        │        │        │        │        │        │        │        │
├────────┴──┬─────┴────────┴────────┴────────┴──┬─────┴────────┴────────┤
│ OVERVIEW  │ SCOPE                             │ TERMINAL              │
│           │                                   │                       │
├───────────┼─────────┬───────────┬─────────────┼───────────────────────┤
│  PULL p   │ PUSH P  │ DOCTOR d  │  REMOVE x   │                       │
├───────────┴─────────┴───────────┴─────────────┴───────────────────────┤
│ ←→ module · : terminal · p pull · P push · d doctor · x remove · q    │
└───────────────────────────────────────────────────────────────────────┘
```

---

## 面板

| 面板 | 位置 | 内容 |
|------|------|------|
| Channel Strip | 顶部 | 模块芯片网格 |
| Overview | 中左 | 全局状态：健康度、统计、系统信息 |
| Scope | 中央 | 选中模块详情：进度条、链接路径、依赖 |
| Terminal | 中右 | 命令输出 + 命令输入 |
| Controls | 底部 | 操作按钮 |
| Footer | 最底 | 快捷键提示 |

---

## 芯片

| 属性 | 值 |
|------|-----|
| 内容尺寸 | 8 列 × 4 行（固定，绝对不变） |
| 含边框尺寸 | 10 × 6 |
| 形状 | 视觉正方形（终端字符 1:2 比例） |
| 内容排��� | 名字 + LED 垂直居中 |
| 选中状态 | 反色（前景/背景互换） |
| 溢出处理 | 横向滚动 |

---

## 面板尺寸

| 面板 | 宽度 | 高度 |
|------|------|------|
| Overview | 总宽 1/4 | 自适应剩余空间 |
| Scope | 总宽 2/4 | 同 Overview |
| Terminal | 总宽 1/4 | 同 Overview |
| Controls | 4 等分 | 1 行 |
| Footer | 全宽 | 1 行 |

---

## 边框

| 属性 | 值 |
|------|-----|
| 结构 | 一个外框 + 内部分割线 |
| 风格 | 直角（不用圆角） |
| 外框 | ┌ ┐ └ ┘ ─ │ |
| 行分割 | ├ ─ ┤ |
| 不同列数行连接 | ┴（上行竖线结束）┬（下行竖线开始）┼（交叉）|
| 颜色 | ANSI "8"（dimmed，跟随终端主题）|

---

## 操作栏

| 按钮 | 图标 | 快捷键 |
|------|------|--------|
| PULL | \uf0ed | p |
| PUSH | \uf0ee | P |
| DOCTOR | \uf21e | d |
| REMOVE | \uf1f8 | x |

- 4 列等分
- 各列之间有竖线分割
- 高度 1 行

---

## 交互

| 操作 | 按键 |
|------|------|
| 切换模块 | ←→ |
| 聚焦 Terminal | `:` |
| 退出 Terminal | esc |
| 翻历史命令 | ↑↓（Terminal 输入模式） |
| 执行操作 | p / P / d / x |
| 添加模块 | a（退出 TUI 提示 `dot add`）|
| 退出 | q |

---

## 执行反馈

- 命令输出显示在 Terminal 面板
- 执行期间操作栏显示 spinner
- 执行完成后自动刷新所有面板数据
