# 文档书写规范

本项目所有设计文档遵循以下规范。

---

## 核心原则

- **声明式** — 描述"是什么"和"规则是什么"，不描述"怎么实现"（实现细节属于代码）
- **结构化** — 用表格、列表、树形图承载信息，避免长段叙述
- **无废话** — 每句话必须传递信息，删掉不影响理解的句子就应该删掉

---

## 格式约定

| 信息类型 | 使用格式 |
|---------|---------|
| 多个实体的属性对比 | 表格 |
| 有序步骤 | 编号列表 |
| 规则/要点 | 无序列表，每条一个要点 |
| 代码结构 | 树形图（缩进 + 竖线） |
| 依赖/流程关系 | ASCII 图 |
| 代码示例 | 围栏代码块，标注语言 |

**不使用：**
- 长段落叙述（超过 3 行的纯文字段落应拆为列表或表格）
- 主观评价
- 实现细节（具体算法步骤、代码行号引用）

---

## 标注约定

- 未实现的功能在描述后标注 **（未实现）**
- 跨文档引用使用 `详见 xxx.md`
