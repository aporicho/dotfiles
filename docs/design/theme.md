# 主题

---

## 配色

- 使用 ANSI 0-15 标准色号
- 不硬编码 hex 颜色值
- 终端主题决定实际颜色（Tokyo Night、Nord 等自动适配）
- 自动检测深色/浅色背景

---

## 语义色

| 用途 | ANSI 色号 |
|------|-----------|
| 健康/成功 | 2（绿） |
| 警告/变更 | 3（黄） |
| 错误/危险 | 1（红） |
| 选中/强调 | 4（蓝） |
| 次要强调 | 5（紫） |
| 信息 | 6（青） |
| 次要文字 | 7 |
| 边框/暗淡 | 8 |

---

## 图标

只使用 Nerd Font 图标。字体：JetBrainsMono Nerd Font。

| 用途 | 图标 | 码点 |
|------|------|------|
| LED 状态灯 | 实心圆 | \uf111 |
| 加密标记 | 锁 | \uf023 |
| Git 变更 | 分支 | \ue725 |
| Pull | 下载 | \uf0ed |
| Push | 上传 | \uf0ee |
| Doctor | 心跳 | \uf21e |
| Remove | 垃圾桶 | \uf1f8 |
| 加载中 | spinner | \uf110 |
| 箭头 | 右箭头 | \uf054 |
