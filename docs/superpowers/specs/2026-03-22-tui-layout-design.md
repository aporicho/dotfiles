# TUI Layout Design Spec

## 概述

整个 TUI dashboard 是**一个外框 + 内部分割线**的网格结构。所有面板都在框架内，用 box-drawing 字符分隔。

## 目标布局

```
┌────────┬────────┬────────┬──────────┬────────┬────────┬────────┬────────┐
│        │        │        │          │        │        │        │        │
│  BIN   │  GIT   │ KITTY  │ NEOVIDE  │  NVIM  │  YAZI  │  ZSH   │ + ADD  │
│   ●    │   ●    │   ●    │    ●     │   ●    │   ●    │  ●     │   a    │
│        │        │        │          │        │        │        │        │
├────────┴──┬─────┴────────┴──────────┴────────┴──┬─────┴────────┴────────┤
│ OVERVIEW  │ SCOPE: BIN                          │ TERMINAL              │
│           │                                     │                       │
│ ████ 100% │ LNK ██████ 1/1                      │ $ dot doctor zsh      │
│           │ GIT ██████ clean                    │   ✓ links healthy     │
│ modules 7 │                                     │                       │
```

## 决策清单

### 1. 芯片（Channel Strip）

| 项�� | 决策 |
|------|------|
| 大小 | **绝对固定**：内容 8 列 × 4 行，加边框 10 × 6 |
| 形状 | 视觉正方形（终端字符 1:2 比例，8×4 刚好） |
| 响应式 | 不随终端缩放，固定不变 |
| 溢出处理 | 横向滚动，显示滚动指示 |
| 内容排布 | 名字 + LED 垂直居中在 4 行内（上下留空） |
| 选中状态 | **反色**（前景色和背景色互换，lipgloss Reverse） |
| 边框 | 有，属于整体外框网格的一部分 |

### 2. 中间面板（Overview / Scope / Terminal）

| 项目 | 决策 |
|------|------|
| 宽度比例 | 1:2:1 |
| 高度 | 三个一样高，自适应剩余空间 |
| 边框 | 有，属于整体外框网格的一部分 |
| 内部边框 | Scope 的 meter box（LNK/SEC/GIT 进度条）保留内部边框 |

### 3. 操作栏（Controls）

| 项目 | 决策 |
|------|------|
| 列数 | 4 列：PULL / PUSH / DOCTOR / REMOVE |
| 宽度 | 等分 |
| 高度 | 1 行 |
| 内部竖线 | 有，4 个按钮之间有竖线分割 |
| 内容 | 图标 + 名称 + 快捷键，居中 |
| 边框 | 有，属于整体外框网格的一部分 |

### 4. Footer

| 项目 | 决策 |
|------|------|
| 位置 | 在外框内，最底部一行 |
| 内容 | 快捷键提示文字 |
| 内部竖线 | 无 |

### 5. 边框系统

| 项目 | 决策 |
|------|------|
| 结构 | 一个外框 + 内部分割线 |
| 角字符 | ┌ ┐ └ ┘ |
| 横线 | ─ |
| 竖线 | │ |
| 行分割连接 | ├ ─ ┤（连接外框左右边） |
| 不同列数行连接 | 芯片竖线结束 ┴，面板竖线开始 ┬，交叉 ┼ |
| 圆角 | 不用，全部直角 |
| 颜色 | theme.PanelBorder()（ANSI "8"，dimmed） |

### 6. 主题和图标

| 项目 | 决策 |
|------|------|
| 配色 | ANSI 0-15 调色板，跟随终端主题 |
| 图标 | 只用 Nerd Font 图标 |
| LED | \uf111（实心圆）|
| 锁 | \uf023 |
| git | \ue725 |
| 下载 | \uf0ed（pull）|
| 上传 | \uf0ee（push）|
| 心跳 | \uf21e（doctor）|
| 垃圾桶 | \uf1f8（remove）|

### 7. 交互

| 项目 | 决策 |
|------|------|
| 芯片���航 | ←→ 切换模块 |
| Terminal 输入 | `:` 聚焦，esc 退出 |
| Terminal 历史 | 支持 ↑↓ 翻历史命令 |

| 项目 | 决策 |

## 实现方案

### frame engine（`frame.go`）

核心算法：接收整个网格的行列定义，一次性绘制完整的外框 + 所有内部分割线。

输入：
```go
type GridRow struct {
    ColWidths []int    // 每列内容宽度
    Contents  []string // 每列预渲染的内容
    Height    int      // 该行内容高度
}

func RenderGrid(rows []GridRow, border lipgloss.Border, style lipgloss.Style) string
```

算法：
1. 绘制顶部边框：`┌` + 第一行列宽 `┬` 分隔 + `┐`
2. 对每一行：绘制内容行（`│` 分隔）
3. 对每对相邻行：绘制分割线，逐列位置判断用 `┴`/`┬`/`┼`/`─`
4. 绘制底部边框：`└` + 最后一行列宽 `┴` 分隔 + `┘`

### layout engine（`layout.go`）

计算每个区域的尺寸并构建 `[]GridRow`。

### dashboard_view.go

调用 layout → 渲染各面板内容 → 调用 frame engine → 输出。
